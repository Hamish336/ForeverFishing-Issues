# Forever Fishing support

Thanks for helping improve Forever Fishing, the fishing addon for WoW Forever. Before you post, [check for an existing report](https://github.com/Hamish336/ForeverFishing-Issues/issues?q=is%3Aissue). If you find one, add any new details there.

- [Report a bug](https://github.com/Hamish336/ForeverFishing-Issues/issues/new?template=01-bug.yml)
- [Suggest a feature](https://github.com/Hamish336/ForeverFishing-Issues/issues/new?template=02-feature.yml)

Anyone can read reports and attachments. You’ll need a free GitHub account to post. Keep private information out of your reports and anything you attach.

For quick questions, use the comments on [Forever Fishing on CurseForge](https://www.curseforge.com/wow/addons/forever-fishing).
